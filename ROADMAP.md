# Roadmap

This roadmap is a working list of product directions, not a promise that every item is scheduled or currently in development.

## Current focus

- [ ] Verify registrar integrations against live official portals and document failures clearly.
- [ ] Improve automated-check diagnostics and manual fallback guidance.
- [ ] Add safe, privacy-conscious test coverage for registrar response variations.
- [ ] Collect feedback from real users before expanding the feature set.

## Planned improvements

- [ ] IPO calendar with upcoming, open and recently closed issues.
- [ ] Better historical IPO result and listing-performance views.
- [ ] Optional watchlist and user-controlled reminders.
- [ ] Improved mobile experience and accessibility.
- [ ] Clear data-source attribution and last-updated timestamps.
- [ ] More robust error handling when third-party endpoints change.

## How to help

- Search [open issues](https://github.com/SatyamGangani/ipo-allotment-checker/issues) before creating a duplicate.
- Open an issue to discuss a proposal before investing time in a large change.
- Never include real PANs, application numbers or other personal data in reports or test fixtures.

Have an idea? [Open a feature request](https://github.com/SatyamGangani/ipo-allotment-checker/issues/new).
