# Security Policy

## Supported versions

There are no tagged releases yet. Security fixes should be prepared against the latest state of the default branch.

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue.

If GitHub private vulnerability reporting is enabled for this repository, use the repository's **Security → Advisories → Report a vulnerability** flow. If that option is unavailable, contact the repository owner through the private contact options on the [GitHub profile](https://github.com/SatyamGangani).

Please include:

- A concise description of the vulnerability and its potential impact.
- Affected file, endpoint, or feature.
- Reproduction steps or a proof of concept that does not expose real personal data.
- Any suggested mitigation.

Do not include real PANs, passwords, access tokens, session cookies, or other people's personal information in a report.

## What to expect

The maintainer will acknowledge reports when reasonably possible, investigate the issue, and coordinate a fix and disclosure. There is currently no guaranteed response or remediation SLA.

## Security-sensitive areas

Please take particular care around PAN storage and transmission, QR profile export/import, registrar API requests, logging, and third-party data sources.
