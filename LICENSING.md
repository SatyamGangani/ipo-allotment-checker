# Licensing and upstream provenance

## Current status

**This repository currently has no software license.** It is publicly viewable on GitHub, but that does not grant general permission to copy, modify, publish, sublicense, or redistribute its contents. The default copyright rules continue to apply unless a valid license is added.

## Why no license was added in this change

The project history and prior development notes identify [DragoHex/IPOAllocationStatus](https://github.com/DragoHex/IPOAllocationStatus) as an upstream project from which this application was initially cloned or derived.

At the time this document was prepared:

- The upstream repository is public.
- GitHub's repository metadata does not identify an SPDX license.
- No root-level `LICENSE` file was present in the upstream repository.
- This repository also has no existing license file.

A public repository without a license is not automatically available for relicensing. Adding an MIT license here could incorrectly grant permissions over code whose copyright and redistribution rights have not been established.

## Before adding a license

The maintainers should:

1. Review the original upstream commit and identify code, assets, and documentation retained from that project.
2. Ask the upstream copyright holder for written permission or obtain confirmation of the applicable license.
3. Review the licenses and attribution requirements for any other copied or vendored material.
4. Decide on a license only after the rights for all included material are understood.
5. Add the complete license text and any required third-party notices in a separate reviewed change.

Until that work is complete, please do not describe this repository as MIT-licensed or invite reuse on the assumption that it is open source.
